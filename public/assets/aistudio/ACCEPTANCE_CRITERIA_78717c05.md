# معیارهای پذیرش و QA

تمام موارد زیر معیار پیشنهادی قابل آزمون هستند، نه نتیجه تست انجام‌شده. وضعیت هر مورد: PASS / FAIL / NOT RUN / N/A همراه شاهد.

| ID | آزمون | انتظار |
|---|---|---|
| G01 | git branch و diff | تغییرات فقط در شاخه مستقل؛ main دست‌نخورده |
| G02 | بررسی فایل‌ها و API | عدم تغییر ناخواسته schema، قرارداد API، auth، secrets |
| L01 | ماژول AI Skills | فقط یک گام در ناحیه مطالعه؛ فهرست همه گام‌های واقعی |
| L02 | قبلی/بعدی/انتخاب | گام صحیح، محدودیت دسترسی و مرز ابتدا/انتها حفظ شود |
| L03 | refresh/back/deep link | رفتار routing و پیشرفت موجود بدون regression |
| L04 | مقایسه داده قبل/بعد | محتوا، ترتیب، شناسه‌ها و انواع محتوای آموزشی حفظ شوند |
| L05 | گام طولانی و متن ترکیبی | بدون clipping؛ متن RTL و کد LTR |
| L06 | تکمیل گام | فقط trigger واقعی موجود وضعیت را تغییر دهد؛ progress از داده واقعی |
| S01 | سندباکس | اجرای واقعی، خروجی و خطا؛ بازگشت به گام؛ حفظ داده طبق قرارداد موجود |
| A01 | مربی AI | ارسال و پاسخ واقعی، خطا و loading؛ عدم افشای کلیدها |
| D01 | داشبورد و roadmap | داده واقعی، مسیر ادامه، قفل و تکمیل درست |
| R01 | viewport 320/390/768/1024/1440 | بدون اسکرول افقی صفحه؛ ناوبری و CTA در دسترس |
| R02 | zoom 200% | متن و کنترل‌ها قابل استفاده، بدون از دست رفتن محتوا |
| X01 | keyboard | Tab، focus، Enter/Space، Esc و بازگشت focus در dialog |
| X02 | contrast | هدف WCAG AA: متن معمولی 4.5:1، بزرگ 3:1، اجزای ضروری 3:1 |
| X03 | semantics | heading، label، نام کنترل و وضعیت قابل تشخیص بدون رنگ |
| V01 | مقایسه با Figma | screenshot قبل/بعد در 1440 و 390؛ اختلافات مستند |
| V02 | خوانایی | متن درس وزن عادی، یک اقدام اصلی، عدم نمایش همه گام‌ها به صورت کارت |
| T01 | dark mode موجود | contrast، کد و انتخاب theme صحیح؛ اگر غایب N/A تا تأیید |
| M01 | نقش مدیر/فراگیر | مجوزها و محدودیت گزارش‌ها بدون تغییر |
| Q01 | lint/typecheck/test/build | دستورات واقعی repo و نتیجه ثبت‌شده؛ خطاهای baseline تفکیک شوند |
| Q02 | performance | مقایسه قبل/بعد در شرایط یکسان؛ regression معنادار توضیح داده شود |
| Q03 | loading/error/empty | حالت‌های واقعی قابل فهم و بدون crash |

## تحویل
- گزارش تست با دستور، محیط، نتیجه و شواهد؛ هیچ PASS بدون اجرا یا بررسی.
- screenshots قبل/بعد در محیط تست، بدون داده شخصی.
- فهرست تفاوت‌های Figma و اجرا، موارد خارج دامنه و بدهی فنی.
- شاخه، commitها و diff؛ PR فقط با مجوز. تأیید مالک قبل از merge/deploy.
