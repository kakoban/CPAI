# Phase 0 Research: دسته‌بندی پنجره‌های زمانی ۲ ساعته و مدیریت کلاس‌های سازمانی

## ۱. تحلیل مکانیزم اسلات‌های زمانی ۲ ساعته (2-Hour Time Window Slots)

تابع `getAutoSlotCode()` در `api/index.ts` در حال حاضر کد اسلات خودکار را تولید می‌کند:
```typescript
function getAutoSlotCode(): string {
  const now = new Date();
  const yyyy = now.getUTCFullYear();
  const mm = String(now.getUTCMonth() + 1).padStart(2, '0');
  const dd = String(now.getUTCDate()).padStart(2, '0');
  const slot = Math.floor(now.getUTCHours() / 2);
  return `${yyyy}${mm}${dd}_SLOT${slot}`;
}
```
این کد یک پنجره زمانی ۲ ساعته دقیق می‌سازد (مثلاً ساعت ۱۰ تا ۱۲ می‌شود اسلات شماره ۵).

### چالش فعلی:
نام این کلاس در دیتابیس به صورت خام `کلاس دوره CPMAI (20261024_SLOT5)` ثبت می‌شود که خوانایی انسانی مناسبی برای جلسات مدیران ندارد.

### راهکار معماری:
1. امکان ویرایش سریع عنوان و نام سازمان برای کلاس‌ها در پنل ادمین (Modal یا Inline edit).
2. افزودن روت سرور `POST /api/admin/classes/update` برای آپدیت فیلدهای `title`، `organization` و `is_active` در جدول `classes`.
3. نمایش عنوان انسانی کلاس در جدول کاربران و کارنامه.

- فیلترهای جدول ادمین:

  - فیلتر دیسیپلین (۱۶ مورد)
  - فیلتر رده سازمانی (مدیر، سرپرست، مهندس، اپراتور)
