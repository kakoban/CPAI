# CPAI Design Handoff v1.0
بسته انتقال بازطراحی سامانه آموزش هوش مصنوعی آکادمی مدیریت اوج به ایجنت کدنویسی.

## شروع سریع
1. ZIP را خارج کنید و پوشه را در workspace ایجنت در کنار مخزن CPAI قرار دهید (ترجیحاً خارج از repo تا زمان تصمیم درباره commit مستندات).
2. مخزن https://github.com/kakoban/CPAI.git را در ایجنت خود باز کنید.
3. محتوای MASTER_PROMPT.md را به ایجنت بدهید. از آن بخواهید همه فایل‌های بسته را بخواند.
4. اگر ایجنت Figma MCP دارد، دسترسی خواندن فایل طراحی را فراهم کنید. در غیر این صورت لینک‌ها را در مرورگر باز کنید یا تصاویر فریم‌ها را به ایجنت بدهید.
5. ابتدا گزارش بررسی سورس، سپس پیاده‌سازی روی برنچ مستقل. نسخه اصلی و production نباید تغییر کنند.

## ترتیب خواندن
AGENTS.md → PRD.md → FIGMA_REFERENCES.md → DESIGN_SYSTEM.md → UI_UX_SPEC.md → MODULE_REDESIGN.md → IMPLEMENTATION_PLAN.md → ACCEPTANCE_CRITERIA.md.

## وضعیت و حدود اعتبار
- ۱۶ فریم Figma و شناسه‌های آن‌ها با خواندن metadata فایل تأیید شده‌اند. این بسته شامل فایل بومی Figma یا خروجی تصویری آن نیست؛ لینک‌ها نیازمند دسترسی مناسب‌اند.
- رنگ‌ها و قواعد طراحی از تصمیمات قبلی گفتگو گرفته شده‌اند؛ توکن‌های تکمیلی پیشنهادی هستند، نه استخراج قطعی همه لایه‌های Figma.
- سورس، معماری، APIها، تست‌ها، دیتابیس و وضعیت برنچ‌های CPAI بررسی نشده‌اند. این بسته کد اجرایی یا ادعای تکمیل پیاده‌سازی ندارد.
- داده‌ها و رفتارهای نمونه در Figma، منبع حقیقت آموزشی یا آماری نیستند. از داده‌های واقعی پروژه استفاده کنید.
- فونت دقیق مکتب‌خونه تأیید نشده؛ Vazirmatn انتخاب طراحی است. هدف الهام بصری است، نه کپی برند.
- اولویت، ماژول‌های داخلی و کاهش بار شناختی است. امکانات جدیدی که در پروژه وجود ندارند نیازمند تأیید جداگانه‌اند.
