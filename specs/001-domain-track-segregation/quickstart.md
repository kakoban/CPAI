# Quickstart: اعتبارسنجی تفکیک دامنه‌ها

## نحوه بررسی و تست کارکرد:

1. **بررسی نوع‌سنجی و کامپایل بدون خطا:**
   ```bash
   npm run lint
   ```
2. **بررسی بیلد موفق فرانت‌اند:**
   ```bash
   npm run build
   ```
3. **تست تعاملی سوئیچر دامنه‌ها در UI:**
   - اجرای سرور توسعه:
     ```bash
     npm run dev
     ```
   - باز کردن مرورگر در آدرس `http://localhost:3000`.
   - کلیک بر روی سوئیچر دامنه در بالای صفحه (تغییر بین "راه و شهرسازی و ابنیه" و "نفت، گاز و پتروشیمی").
   - مشاهده تغییر آنی مثال‌های فازها و سناریوها در کاربرگ‌ها و کارگاه بدون رفرش صفحه.
