# Quickstart: تست و اعتبارسنجی شخصی‌سازی دیسیپلین‌ها و رده‌ها

## مراحل تست و اعتبارسنجی:

1. **بررسی نوع‌سنجی TypeScript:**
   ```bash
   npm run lint
   ```
2. **بررسی بیلد موفق:**
   ```bash
   npm run build
   ```
3. **تست تعاملی انتخاب دیسیپلین در UI:**
   - اجرای سرور لوکال: `npm run dev`
   - ورود به برنامه در آدرس `http://localhost:3000`.
   - کلیک بر روی چیپ یا دکمه «دیسیپلین تخصصی شما» در نوار ابزار.
   - انتخاب دیسیپلین (مثلاً «مهندسی و اجرای پایپینگ» در پتروشیمی یا «دفتر فنی و کلیم‌های قراردادی» در عمران).
   - مراجعه به صفحه ۲ (تعریف مسئله) یا صفحه ۳ (معیارهای موفقیت) و کلیک بر روی «درج نمونه موردی».
   - مشاهده تغییر خودکار اصطلاحات تخصصی بر اساس همان دیسیپلین انتخابی.
