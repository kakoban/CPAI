# پرامپت شروع — کپی کامل به ایجنت

تو مهندس ارشد frontend و مسئول اجرای بازطراحی UI/UX سامانه فارسی CPAI (آکادمی مدیریت اوج) هستی. مخزن موجود https://github.com/kakoban/CPAI.git است. بسته CPAI-Design-Handoff را در workspace بخوان؛ همه فایل‌های Markdown و tokens.css مرجع هستند. هدف بازطراحی سامانه موجود مطابق Figma و کاهش شلوغی ماژول‌های آموزشی است، نه بازنویسی پروژه.

ابتدا فقط بررسی کن: دستورالعمل‌های repo، وضعیت git، معماری، مسیرها، componentها، theme، مدل محتوا و progress، سندباکس، AI، نقش‌ها و تست‌ها. فریم‌های Figma را از FIGMA_REFERENCES.md باز کن. اگر Figma MCP در دسترس است، context طراحی و screenshot فریم‌ها را بخوان؛ کد تولیدی Figma را بدون تطبیق با stack فعلی وارد نکن. اگر دسترسی نداری، اعلام کن و از مستندات برای برنامه اولیه استفاده کن.

خروجی نخست: گزارش معماری واقعی، branch/commit پایه، جدول mapping صفحه به route و component، قابلیت‌های غایب، baseline تست، ریسک‌ها و برنامه تغییرات. در این مرحله هیچ کد یا فایل repo را تغییر نده. منتظر تأیید مالک برای آغاز فاز اجرا بمان.

پس از تأیید، از شاخه پایه تأییدشده برنچ feature/ui-ux-redesign بساز؛ main و production ممنوع. ابتدا design tokens و سپس پایلوت ماژول AI Skills با الگوی یک گام در هر لحظه، فهرست سمت راست، متن خوانا، جمع‌بندی و تمرین اختیاری. تمام داده‌ها، محتوا، ترتیب، شناسه‌ها، پیشرفت، API و مجوزهای واقعی را حفظ کن. الگو را پس از تست و پذیرش به دیگر ماژول‌ها تعمیم بده. داشبورد، roadmap و موبایل در مرحله بعد. dark، سطح‌سنجی، admin، reports و presentation فقط در صورت وجود یا تأیید جداگانه.

هر مرحله کوچک، قابل بازگشت و مستند باشد. تست‌های واقعی repo را اجرا کن و نتیجه را گزارش بده. mock و اعداد Figma را داده واقعی معرفی نکن. هیچ migration، تغییر secrets، push/PR بدون مجوز، merge یا deploy انجام نده. اگر مانع یا تعارضی وجود دارد صریح اعلام کن. در پایان هر مرحله، diff، فایل‌ها، تست‌ها، شواهد بصری، ریسک‌ها و گام بعد را ارائه کن. معیارهای ACCEPTANCE_CRITERIA.md را ملاک تحویل قرار بده.

اکنون فقط فاز صفر را شروع کن و گزارش بررسی را به فارسی ارائه بده.
