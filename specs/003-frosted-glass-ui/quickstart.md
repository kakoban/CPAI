# Quickstart: تست و اعتبارسنجی پوسته گلس مات

## مراحل اعتبارسنجی بصری و عملکردی:

1. **بررسی عدم وجود خطای کامپایل:**
   ```bash
   npm run lint
   npm run build
   ```
2. **تست بصری سایدبار شیشه‌ای:**
   - سرور را اجرا کنید: `npm run dev`
   - در مرورگر به آدرس `http://localhost:3000` بروید.
   - سایدبار را روی صفحه باز بگذارید و به پایین اسکرول کنید.
   - مطمئن شوید کارت‌ها و متون صفحه با محو شدن شیشه‌ای و اشباع نوری ۲۶ پیکسلی از زیر سایدبار دیده می‌شوند.
3. **تست مدال شیشه‌ای مات:**
   - روی دکمه دیسیپلین در بالای صفحه کلیک کنید.
   - کادر مدال باید با افکت بلور عمیق و هایلایت شیشه‌ای بدون بردر کدر ظاهر شود.
