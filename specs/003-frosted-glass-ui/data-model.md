# Phase 1 Data Model: توکن‌های طراحی گلس مات (Design Tokens)

## ۱. متغیرهای CSS و پالت گلس مات

| نام توکن | تم روشن (Light) | تم تاریک (Dark) | کاربرد |
| :--- | :--- | :--- | :--- |
| `--glass` | `rgba(250, 253, 252, 0.62)` | `rgba(15, 31, 34, 0.58)` | پس‌زمینه اصلی سایدبار و پنجره دیالوگ |
| `--glass-line` | `rgba(255, 255, 255, 0.8)` | `rgba(255, 255, 255, 0.12)` | خط نوری لبه و هایلایت داخلی شیشه |
| `--tile` | `rgba(255, 255, 255, 0.5)` | `rgba(255, 255, 255, 0.04)` | کاشی‌های گزینه‌ها و کارت‌های داخلی |
| `--tile-hover` | `rgba(18, 52, 59, 0.06)` | `rgba(255, 255, 255, 0.07)` | وضعیت هاور کاشی‌ها |
| `--tile-active`| `rgba(253, 240, 216, 0.78)` | `rgba(66, 52, 22, 0.70)` | پس‌زمینه آیتم انتخاب‌شده |
| `--sheen` | `rgba(255, 255, 255, 0.32)` | `rgba(255, 255, 255, 0.06)` | لایه نوری انکسار زاویه‌دار |

## ۲. مشخصات فیلترهای پس‌زمینه
- `backdrop-filter: blur(26px) saturate(1.6);`
- `-webkit-backdrop-filter: blur(26px) saturate(1.6);`
