# Quickstart: تست و اعتبارسنجی مدیریت کلاس‌ها و دیسیپلین‌ها

## مراحل تست و اعتبارسنجی:

1. **بررسی نوع‌سنجی TypeScript:**
   ```bash
   npm run lint
   npm run build
   ```
2. **تست تعاملی در پنل ادمین:**
   - اجرای سرور لوکال: `npm run dev`
   - ورود به پنل ادمین با کلیک روی دکمه بنفش «پنل مدیریت» در هدر.
   - ورود به تب جدید «مدیریت کلاس‌ها و دوره‌ها».
   - مشاهده کلاس‌های اسلات ۲ ساعته (مانند `SLOT5`).
   - کلیک روی آیکون ویرایش و تغییر نام کلاس به یک نام سازمانی دلخواه.
   - بازگشت به تب «کاربران» و فیلتر کردن بر اساس کلاس جدید و دیسیپلین‌های تخصصی.
   - کلیک روی دانلود CSV و مشاهده خروجی در اکسل.
